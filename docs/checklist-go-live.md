# Checklist de Go-Live (Vercel)

## Infra
- Projeto de produção criado na Vercel.
- Ambiente staging separado.
- Variáveis de ambiente configuradas.

## Segurança
- Auth funcionando em produção.
- Rotas de dashboard protegidas.
- Isolamento por tenant validado.
- Rate limit na rota pública de mensagens.

## Banco
- Migrações aplicadas.
- Índices conferidos.
- Backup agendado.

## Produto
- Edição draft/publish funcionando.
- Formulário de mensagem funcionando.
- Inbox no painel funcionando.
- Upload de imagem funcionando.

## Domínios
- Subdomínios por tenant funcionando.
- SSL ativo.
- Domínio custom (se houver) validado.

## Observabilidade
- Logs de erro ativos.
- Alertas básicos ativos.
- Página de status interna definida.

## Operação
- Processo de onboarding de cliente documentado.
- Processo de suporte e SLA documentado.
- Processo de offboarding documentado.
